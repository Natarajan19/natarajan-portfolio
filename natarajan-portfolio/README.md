# Natarajan Portfolio

A responsive React + Vite portfolio starter.

## Run locally

1. Install Node.js (LTS): https://nodejs.org/
2. Extract this folder.
3. Open a terminal in this folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Before publishing

- Replace the placeholder email address in `src/main.jsx`.
- Replace the generic LinkedIn and GitHub links with your actual profile URLs.
- Add your own profile photo and update the hero section if desired.
- Verify every project description, achievement, metric and date.
- Add GitHub repository and live-demo links for projects where available.
- Do not publish private phone numbers, home address, student IDs or other sensitive details.

## Build for production

```bash
npm run build
```

The production website is generated in the `dist` folder.

## Deploy

Push the project to GitHub, then import that repository into Vercel:
https://vercel.com/new

## Google visibility

After deployment:
1. Add and verify your site in Google Search Console: https://search.google.com/search-console/
2. Submit your sitemap (add one before submitting if you expand the site to multiple pages).
3. Use URL Inspection to request indexing of the homepage.
4. Test the ProfilePage structured data using Google's Rich Results Test:
   https://search.google.com/test/rich-results

Google indexing and rankings are not guaranteed. Structured data helps Google understand the profile; it does not guarantee a knowledge panel or a first-place result.
